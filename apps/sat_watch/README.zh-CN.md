# 饱和监看

实时提示读数达到读出电路上限的单元。

读数达到读出电路上限的单元，报告的是该上限，而不是它所承受的压力。它处于削顶状态的每一帧，都是事后无法恢复的数据，所以此应用会在你还来得及卸下传感器上的载荷或更换反馈电阻时及时提示。

当任一单元读数达到 1050 或以上并持续 50 ms 时，LED 和灯条最后一个像素变红。这次饱和结束时，会报告它波及了多少个单元以及持续了多久。

**调整**：1050 适用于 8.2 kOhm 的反馈电阻，其上限约为 1110 uS。请将它设为略低于你自己电路的上限（修改 `active(1050)` 后重新构建）。

**事件**：`clipping`（上升沿/下降沿）、`clip_cells`（同时削顶的最多单元数）、`clip_ms`（这次饱和的时长）。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
