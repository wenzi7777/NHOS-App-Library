# 飽和ウォッチ

読み出し回路の上限に張り付いたセルをその場で知らせます。

読み出し回路の上限に達したセルは、そのセルにかかっている圧力ではなく上限値を報告します。クリップしている間のフレームはすべて後から復元できないデータなので、このアプリはセンサーから荷重を抜いたりフィードバック抵抗を変えたりできるうちに、その場で知らせます。

いずれかのセルが 50 ms の間 1050 以上を示すと、LED とストリップの最後のピクセルが赤になります。その状態が終わると、何個のセルに及んだか、どれくらい続いたかを報告します。

**調整:** 1050 は 8.2 kOhm のフィードバック抵抗（上限は約 1110 uS）に適した値です。ご自身の回路の上限より少し低い値に設定してください（`active(1050)` を編集して再ビルドします）。

**イベント:** `clipping`（立ち上がり/立ち下がり）、`clip_cells`（同時にクリップした最大セル数）、`clip_ms`（その状態の長さ）。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
