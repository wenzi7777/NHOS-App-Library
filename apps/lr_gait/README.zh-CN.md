# 左右对称性

左右载荷占比与峰值，提示持续的不对称。

每一半所占的载荷比例（在一秒内取平均）、每一半的峰值单元，以及当分配比例超过 65/35 并持续两秒时发出的 `lopsided` 事件。两半以百分比划分，因此适用于任何矩阵，包括并排放置的两只鞋垫。

**事件**：`lopsided`（上升沿/下降沿）、`share`（开始时的左侧占比）。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
