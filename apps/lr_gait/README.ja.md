# 左右対称性

左右の荷重比とピーク。持続する非対称を検出。

左右それぞれが占める荷重の割合（1 秒間の平均）、左右それぞれのピークセル、そして配分が 65/35 より偏った状態が 2 秒間続いたときの `lopsided` イベントを出力します。左右の半分はパーセントで指定しているため、左右に並べた 2 枚のインソールを含め、どのマトリクスでも使えます。

**イベント:** `lopsided`（立ち上がり/立ち下がり）、`share`（始まった時点の左側の割合）。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
