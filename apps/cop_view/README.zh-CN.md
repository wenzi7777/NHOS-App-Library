# 压力中心

前后、左右载荷偏移及倾斜事件。

载荷所在的位置，以两个 -1 到 +1 的偏移表示：前（+）相对于后，以及右（+）相对于左，每个都在半秒内取平均，因此身体摇摆会被计入，而一次落脚不会。偏移超过 0.3 时触发倾斜事件。

它基于按百分比划分的区域总和，而不是以行和列计的质心，因此偏移在任何矩阵上的含义都相同。

**事件**：`lean_front`、`lean_back`、`lean_left`、`lean_right`（上升沿/下降沿）。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
