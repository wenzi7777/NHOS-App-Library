# 圧力中心

前後・左右の荷重バイアスと傾きイベント。

荷重がどこにかかっているかを、-1〜+1 の 2 つのバイアスとして表します。前（+）対後、右（+）対左の 2 つで、それぞれ 0.5 秒間で平均するため、体の揺れは反映され、一歩の着地は反映されません。バイアスが 0.3 を超えると傾きイベントが立ち上がります。

行と列で表した重心ではなく、パーセントで指定した領域の合計から算出しているため、バイアスはどのマトリクスでも同じ意味を持ちます。

**イベント:** `lean_front`、`lean_back`、`lean_left`、`lean_right`（立ち上がり/立ち下がり）。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
