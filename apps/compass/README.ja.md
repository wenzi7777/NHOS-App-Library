# コンパス

方位と磁場強度を表示し、近くの磁石を検出します。

磁気センサーによる方位（0-360 度。磁北から 15 度以内ではストリップの最初のピクセルが青になります）と磁場強度を表示します。方位は傾き補正されていないため、コンパスとして使えるのはボードを水平に置いている間だけです。

磁場強度はどの向きでも使えます。近くに磁石があると、地磁気の 25-65 uT をはるかに超える値になります。150 uT を超えると `magnet` が立ち上がるので、非接触スイッチとして使えます。

**イベント:** `north`、`magnet`（立ち上がり/立ち下がり）、`magnet_ut`（磁石が近くにあった間の最大磁場）。

**必要環境:** New Horizons OS v1.6.0 と、磁気センサーを搭載したボード。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
