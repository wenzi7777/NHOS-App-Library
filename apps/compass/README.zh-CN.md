# 指南针

显示方位与磁场强度，检测附近的磁铁。

来自磁力计的方位（0-360 度；在磁北 15 度以内时，灯条第一个像素变蓝）以及磁场强度。方位未做倾斜补偿，因此只有在板平放时才能当作指南针。

磁场强度在任何朝向下都有效，附近的磁铁会使它远高于地球磁场的 25-65 uT：超过 150 uT 时触发 `magnet`，可用作非接触式开关。

**事件**：`north`、`magnet`（上升沿/下降沿）、`magnet_ut`（磁铁靠近期间的最强磁场）。

**需要**：New Horizons OS v1.6.0 以及带磁力计的板。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
