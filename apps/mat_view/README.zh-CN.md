# 垫面视图

在 OLED 显示前后载荷，按按钮切换到第 2 页。

第 1 页显示前半部与后半部的载荷，并以条形显示后半部的占比；短按动作按钮翻到第 2 页，显示峰值单元、受载单元的数量以及压力中心所在的行。

两半以百分比给出，因此同一个包既能划分 15x15 的垫子，也能划分 5x7 的传感器。

**需要**：New Horizons OS v1.6.0 以及 OLED（v1.0.F / v1.5.F），并且设备的 OLED 页面需设为 `app`。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
