# Mat View

Front/rear load on the OLED; press the button for page 2.

Page 1 shows the load on the front and rear halves and the rear's share
as a bar; a short press of the action button turns to page 2 with the peak
cell, the number of loaded cells and the centre of pressure's row.

The halves are given in percent, so the same package splits a 15x15 mat and
a 5x7 sensor.

**Needs:** New Horizons OS v1.6.0 and the OLED (v1.0.F / v1.5.F), with the
device's OLED page set to `app`.

The source is [`app.nhs`](app.nhs); `app.nha` is compiled from it.
Install from the Apps page in the New Horizons Desktop app.

See the [authoring guide](../../docs/authoring.md) for the op reference and the
cost model.
