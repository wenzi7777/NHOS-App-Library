# マットビュー

前後の荷重を OLED に表示。ボタンで 2 ページ目へ。

1 ページ目には前半分と後半分の荷重、および後半分の割合を示すバーが表示されます。アクションボタンを短く押すと 2 ページ目に切り替わり、ピークセル、荷重がかかっているセルの数、圧力中心の行が表示されます。

前後の半分はパーセントで指定しているため、同じパッケージで 15x15 のマットも 5x7 のセンサーも分割できます。

**必要環境:** New Horizons OS v1.6.0 と OLED（v1.0.F / v1.5.F）。デバイスの OLED ページを `app` に設定しておく必要があります。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
