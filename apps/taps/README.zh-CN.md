# 点按计数

统计按压次数并记录每次按住时长，按按钮清零。

适用于手指点按和按住训练。传感器上任何位置的每次按压都会被计数；按压结束时，会报告按住了多久。OLED 显示计数、上一次按住的时长以及频率（每分钟按压次数）。短按动作按钮会将计数清零。

**事件**：`press`（上升沿/下降沿）、`tap`（值：计数）、`hold_ms`（值：按住时长，在按压结束时报告）。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
