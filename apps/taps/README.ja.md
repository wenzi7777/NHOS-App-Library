# タップカウンター

押下回数を数え、各押下の保持時間を計測。ボタンでリセット。

指タッピングや押したまま保持する運動のためのアプリです。センサー上のどこを押しても 1 回として数えられ、押下が終わると保持していた時間が報告されます。OLED には回数、直前の保持時間、レート（1 分あたりの押下回数）が表示されます。アクションボタンを短く押すと回数がリセットされます。

**イベント:** `press`（立ち上がり/立ち下がり）、`tap`（値: 回数）、`hold_ms`（値: 保持時間。押下の終わりに報告）。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
