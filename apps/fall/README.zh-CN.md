# 跌倒检测

冲击后保持静止即发出跌倒警报。

一次剧烈冲击（超过 2.5 g），随后是两秒无动作，且这段静止须在冲击后七秒内开始。单独出现其中任何一种都很常见；两者同时出现才是跌倒的样子。发生跌倒时，LED 和灯条最后一个像素变红，并记录 `fallen`。

在后台运行，因此在没有任何串流时也会持续监测。此时它每秒只查看 IMU 十次，而不是每帧一次，短暂的冲击可能恰好落在两次查看之间：串流时要可靠得多。

**事件**：`impact`、`moving`、`fallen`（上升沿/下降沿）。

**需要**：New Horizons OS v1.6.0 以及带 IMU 的板。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
