# 実験マーカー

ボタンを押すと番号付きマークをイベントログに記録します。

アクションボタンを短く押すたびに、その番号（1, 2, 3, ...）を持つ `mark` イベントが記録されます。Desktop はアプリのイベントを、録画データの `.events.csv` に、それが発生したフレームと並べて書き込むため、マークはサンプルと対応します。ストップウォッチがなくても「試行 3 はここで開始」とわかります。

OLED には最新のマーク番号と、そこからの経過秒数が表示されます。

**イベント:** `mark`（値: マークの番号）。

**必要環境:** New Horizons OS v1.6.0。OLED は任意です（v1.0.F / v1.5.F）。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
