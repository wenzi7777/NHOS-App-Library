# 实验标记

按下按钮即在事件日志中记录带编号的标记。

每次短按动作按钮都会记录一个带有其编号（1、2、3……）的 `mark` 事件。Desktop 会把应用事件写入录制文件的 `.events.csv`，并放在事件发生时的那一帧旁边，因此标记与采样一一对齐：无需秒表就能标出“第 3 次试验从这里开始”。

OLED 显示最新的标记编号以及自该标记以来经过的秒数。

**事件**：`mark`（值：标记的编号）。

**需要**：New Horizons OS v1.6.0；OLED 为可选（v1.0.F / v1.5.F）。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
