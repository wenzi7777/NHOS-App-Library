# 荷重ストリップ

総荷重を LED メーターで表示し、接触と過負荷を示します。

総荷重を外部 LED ストリップ上のメーターとして表示します。色は最初のピクセルの緑から最後のピクセルの赤まで変化します。接触すると最初のピクセルが青になり、いずれかのセルがフルスケールに近づくと最後のピクセルが赤になります。OLED や Desktop を使わなくても、ストリップを一目見るだけで、センサーに荷重がかかっているかどうかと、その大きさがわかります。

**調整:** メーターの範囲（`0..20000`）と過負荷レベル（`1800`）はセンサーによって異なります。

**必要環境:** New Horizons OS v1.5.0 と、ストリップを搭載したボード（v1.0.F は 3 ピクセル、v1.5.F は 9 ピクセル）。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
