# 载荷灯条

以 LED 灯条显示总载荷，并提示接触与过载。

沿外置 LED 灯条以仪表形式显示总载荷，从第一个像素的绿色到最后一个像素的红色。有接触时第一个像素变蓝，任一单元接近满量程时最后一个像素变红。看一眼灯条就能知道传感器是否受载、受载多少，无需 OLED 或 Desktop。

**调整**：仪表的量程（`0..20000`）和过载阈值（`1800`）取决于你的传感器。

**需要**：New Horizons OS v1.5.0 以及带灯条的板（v1.0.F 显示 3 个像素，v1.5.F 显示 9 个）。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
