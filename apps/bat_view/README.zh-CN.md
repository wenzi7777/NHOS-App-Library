# 电量与连接

电量、连接状态与离线时长，低电量时提醒。

显示电池电量、设备是否有可串流的 Gateway 或 Hub（有时灯条第一个像素为绿色）、已离线多长时间，以及运行时间。电量低于 15 % 并持续五秒时，LED 和灯条最后一个像素变红，并记录 `low_battery`。

在后台运行，因此在没有任何串流时也能继续工作——而这正是你最想知道的时候。没有电量计的板显示 -1，且从不发出提醒。

**事件**：`low`（上升沿/下降沿）、`low_battery`（电量）。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
