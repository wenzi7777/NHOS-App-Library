# バッテリーと接続

電池残量・接続状態・オフライン時間。低残量を警告。

バッテリーの充電残量、デバイスにストリーミング先の Gateway または Hub があるかどうか（ある間はストリップの最初のピクセルが緑になります）、オフラインになってからの時間、稼働時間を表示します。残量が 15 % を下回った状態が 5 秒続くと、LED と最後のピクセルが赤になり、`low_battery` が記録されます。

バックグラウンドで動作するため、何もストリーミングしていないとき、つまり最も状態を知りたいときにも動き続けます。フューエルゲージのないボードでは -1 と表示され、警告は出ません。

**イベント:** `low`（立ち上がり/立ち下がり）、`low_battery`（その時点の残量）。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
