# 歩数計

かかとの接地を数えます。再起動後も保持、ボタンでリセット。

マトリクス後半部でのかかとの接地を数え、歩数とケイデンス（直近 2 回の接地から求めた 1 分あたりの歩数）を表示します。歩数はデバイスの NVS に保存されるため、再起動後も保持されます。アクションボタンを短く押すと 0 からやり直します。アプリをアンインストールした場合や、新しいバージョンをインストールした場合も 0 から始まります。

**調整:** 接地レベル（`300`）はセンサーと装着者によって異なります。

**イベント:** `strike`（立ち上がり/立ち下がり）、`step`（値: 歩数）。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
