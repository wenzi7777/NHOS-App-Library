# 计步器

统计脚跟着地次数，重启后保留，按按钮清零。

统计矩阵后半部的脚跟着地次数，并显示计数与步频（每分钟步数，根据最近两次着地计算）。计数保存在设备的 NVS 中，因此重启后仍会保留；短按动作按钮会重新开始计数。卸载该应用或安装新版本时，也会从零开始。

**调整**：着地阈值（`300`）取决于你的传感器和佩戴者。

**事件**：`strike`（上升沿/下降沿）、`step`（值：计数）。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
