# 持続荷重

連続荷重の時間を計測し、20 分で警告します。

体重移動を促すリマインダーです。同じ場所に荷重がかかり続けることが褥瘡の始まりです。このアプリは連続荷重の時間を計測し、20 分を過ぎると LED を赤にして `relieve` を記録します。

30 s のデバウンスは双方向に働きます。荷重がかかってから 30 s 後に計測が始まり、体重を移したときは荷重が本当に 30 s 抜けた場合にだけ時計がリセットされるので、もぞもぞ動いただけではリセットされません。

**調整:** 荷重レベル（`300`）と上限時間（`20` 分）。

**イベント:** `loaded`、`overdue`（立ち上がり/立ち下がり）、`relieve`（荷重がかかっていた分数）、`loaded_min`（各荷重期間の長さ。期間の終わりに出力）。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
