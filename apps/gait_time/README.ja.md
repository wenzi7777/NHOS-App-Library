# 歩行タイミング

各歩の立脚時間とストライド時間。

歩ごとの時間的な歩行パラメータです。立脚時間（足が地面に着いていた時間）を各歩の終わりに、ストライド時間（接地から次の接地まで）を各歩の始まりに出力します。どちらもウィンドウを使わないため、ゆっくり歩いても速く歩いても同じ精度で計測できます。OLED にはデューティファクター（各ストライドのうち接地している時間の割合）も表示されます。

セッションの最初の `stride_ms` は 0 です。ストライドには 2 回の接地が必要なためです。

**イベント:** `stance`（立ち上がり/立ち下がり）、`stance_ms`、`stride_ms`。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
