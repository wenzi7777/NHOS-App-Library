# 步态时间

每一步的支撑时间与步幅时间。

逐步给出的时间类步态参数：每一步结束时给出支撑时间（脚在地面上停留了多久），每一步开始时给出步幅时间（从一次触地到下一次触地）。两者都不使用时间窗，因此慢走与快走的计时同样准确。OLED 还会显示占空因子：每个步幅中脚在地面上的时间占比。

一次会话中的第一个 `stride_ms` 为 0：一个步幅需要两次触地。

**事件**：`stance`（上升沿/下降沿）、`stance_ms`、`stride_ms`。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
