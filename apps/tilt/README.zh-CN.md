# 倾斜警报

显示 IMU 俯仰与横滚角，持续倾斜时发出警报。

根据重力方向计算俯仰角与横滚角。在你想保持的姿势下，将板以元件面朝上平放安装：倾斜超过 25 度并持续三秒时触发 `slouch` 并使 LED 变红，倾斜结束时报告倾斜的最大程度。灯条以仪表形式显示倾斜程度，最大到 45 度。

只有在板不动时，重力才等于全部加速度，因此它读取的是姿势，而不是运动。

**事件**：`slouch`（上升沿/下降沿）、`slouch_deg`（最大倾斜角度）。

**需要**：New Horizons OS v1.6.0 以及带 IMU 的板。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
