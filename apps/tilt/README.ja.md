# 傾きアラーム

IMU のピッチ・ロールを表示し、傾きが続くと警告。

重力の方向からピッチとロールを求めます。ボードを部品面を上にして水平に、維持したい姿勢で取り付けてください。25 度を超える傾きが 3 秒続くと `slouch` が立ち上がって LED が赤になり、終わったときにどこまで傾いたかが報告されます。ストリップには 45 度までの傾きがメーターとして表示されます。

重力が加速度のすべてになるのはボードが動いていない間だけなので、このアプリが読み取るのは動きではなく姿勢です。

**イベント:** `slouch`（立ち上がり/立ち下がり）、`slouch_deg`（最大の傾き）。

**必要環境:** New Horizons OS v1.6.0 と、IMU を搭載したボード。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
