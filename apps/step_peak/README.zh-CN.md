# 单步峰值

在每一步结束时输出峰值单元与峰值载荷。

每一步中最高的单个单元读数和最高的总载荷，在该步结束时报告。运行中的最大值会在每次触地时重新开始，因此一次很重的步伐不会掩盖之后的步伐——这一点与固定时间窗不同。

**事件**：`stance`（上升沿/下降沿）、`step_cell`、`step_load`。

**需要**：New Horizons OS v1.6.0。

源代码为 [`app.nhs`](app.nhs)；`app.nha` 由它编译生成。
请在 New Horizons Desktop 的「应用」页面安装。

运算符参考与开销模型请参见[编写指南](../../docs/authoring.md)。
