# ステップピーク

各歩のピークセル値とピーク荷重を歩の終わりに出力。

各歩で最も高い単一セルの値と最も高い総荷重を、その歩が終わった時点で報告します。最大値は接地のたびにリセットされるため、固定ウィンドウとは異なり、1 回の重い歩がその後の歩を覆い隠すことはありません。

**イベント:** `stance`（立ち上がり/立ち下がり）、`step_cell`、`step_load`。

**必要環境:** New Horizons OS v1.6.0。

ソースは [`app.nhs`](app.nhs) で、`app.nha` はそこからコンパイルされます。
New Horizons Desktop の「アプリ」ページからインストールしてください。

op リファレンスとコストモデルについては、[作成ガイド](../../docs/authoring.md)を参照してください。
